# 📖 Lessons

Twelve chapters follow one expedition from choosing a data primitive to running
the complete architecture safely. Read them in order: each chapter opens with a
problem, derives the Azure mechanism, runs a companion, and ends with practice,
diagnosis, retrieval questions, and a bridge to the next decision.

## 🗂️ Chapters

1. [`01-azure-data-map/`](01-azure-data-map/) — choose among blobs, queues, tables, streams, and documents.
2. [`02-azure-sdk-foundations/`](02-azure-sdk-foundations/) — build testable Azure SDK clients.
3. [`03-storage-account/`](03-storage-account/) — define the shared Storage boundary.
4. [`04-blob-storage/`](04-blob-storage/) — preserve and stream expedition artifacts.
5. [`05-blob-lifecycle/`](05-blob-lifecycle/) — coordinate writers and retention.
6. [`06-queue-storage/`](06-queue-storage/) — dispatch idempotent work.
7. [`07-table-storage/`](07-table-storage/) — design point-readable observation indexes.
8. [`08-event-hubs-model/`](08-event-hubs-model/) — model partitioned telemetry streams.
9. [`09-event-hubs-processing/`](09-event-hubs-processing/) — own, checkpoint, and recover processors.
10. [`10-cosmos-modeling/`](10-cosmos-modeling/) — choose partition, throughput, and indexing models.
11. [`11-cosmos-development/`](11-cosmos-development/) — query and update Cosmos DB safely.
12. [`12-secure-operable-cloud/`](12-secure-operable-cloud/) — prove identity, cost, diagnostics, and cleanup.

## 🔁 Reading loop

Preview the question, predict companion output, run it, change one variable,
complete the matching exercise, and answer the review questions from memory.
