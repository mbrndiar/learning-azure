# 🏆 Capstones

The [`Cloud Expedition Field Journal`](cloud-expedition-journal/README.md) is
the course's required final destination. It integrates Event Hubs, Blob, Queue,
Table, and Cosmos DB behind application-owned ports, then proves replay,
throttling, poison-work, identity, and cleanup behavior with deterministic
tests.

The complete grade is offline. Running the same architecture in live Azure is
an optional, opt-in, billable extension.
